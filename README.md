# ミライスターフォース スライド デザインシステム

「読む資料」型のスライドを、統一感のあるフォーマットで素早く作るためのデザインシステムです。
**ブルー基調 × 游ゴシック**。HTML/CSS で 16:9 のスライドを組み、トークン（色・サイズ）と
レイアウトの「型」をルール化しています。各フォーマットは、一般的なスライドデザインの定石
（外部のスライドデザイン解説記事など）を参考に定義しています。

## 使い方

- **Claude / Claude Design で使う**：このフォルダごと Claude Design の
  「Link code from your computer」に読み込ませると、ここで定義した色・フォント・型に沿って
  スライドを生成できます。
- **そのまま見る／組む**：`example-deck.html` をブラウザで開くと、全フォーマットの作例が一覧できます。
  新しいスライドは `slides.css` の型クラスを組み合わせて作り、色やサイズは `tokens.css` の
  CSS変数から参照します（直接ベタ書きしない）。

> **設計方針：下の「使えるフォーマット」にある型以外の形は作らない。**
> カード型、英語ラベル（AGENDA / POINT 等）、フッターやページ番号などは使いません。

## 0. ファイル構成

| ファイル / フォルダ | 役割 |
| --- | --- |
| `tokens.css` | カラー・フォント・サイズの**唯一の出典** |
| `slides.css` | **型A〜P**のレイアウト |
| `example-deck.html` | 全フォーマットの作例。**新規スライドはこれを下敷きにする** |
| `assets/logo/` | 会社ロゴ（黒・透過 PNG） |
| `assets/illust/` | イラスト（SVG・全100点） |
| `assets/gradient/` | ブルー系の背景（写真の代わりに使用可） |

---

## 1. フォント（必須）

- **游ゴシックを使う。**
  `"游ゴシック体", "Yu Gothic", YuGothic, "游ゴシック", "Hiragino Kaku Gothic ProN", "Meiryo", sans-serif`
- **タイトルは太字(Bold)、本文・説明文は細字(Regular)**。文字の大きさと太さで視線を誘導する（メリハリ）。

## 2. カラー（増やさない／強調は1色だけ）

| 役割 | 色 | HEX |
| --- | --- | --- |
| ベース（最大面積） | 白 | `#FFFFFF` |
| タイトル文字 | 濃紺（ほぼ黒） | `#1B2330` |
| 本文・説明文 | グレイッシュ | `#39434F` |
| 目立たせない部分 | 薄いグレー | `#B9C0C8` |
| **メインカラー** | **青** | **`#1A7FE0`** |
| **強調（1色だけ）** | **ピンク** | **`#EC6A8E`**（薄ピンク `#FBDDE7`） |
| サブ（表・図） | グレー | ヘッダー `#9C9C9C` / セル `#EDEDED` |
| 装飾の丸 | 緑 | `#2ECB6E` |

- **青がメインカラー**：背景を青にした強調スライド、青いタイトルに使う。
- **強調は必ず1色に絞る**：表は強調列だけピンク、フロー図は強調ステップだけピンク。色をたくさん使って強調しない。
- **強調しないなら色を統一する**：順序や並びを見せるだけ（どこも強調しない）スライドは、逆に全要素を同じ1色にそろえる。1箇所だけ色を変えない。例＝フロー図で進め方を強調＝1色だけピンク／流れを示すだけ＝全部同じ色（青）。
- 文中の強調も `青` か `ピンク` の**どちらか1色**に統一する。

## 3. 共通ルール（参考画像に共通する作法）

- **余白をたっぷり取る**（左右96px・上下72px目安）。詰め込まない＝1スライド1メッセージ。
- **位置・大きさ・形をそろえる**：画像は同じ大きさの正方形、間隔も均等に。
- **フッター・ページ番号・ロゴは各スライドに置かない**（参考画像に無い）。ロゴは**表紙と裏表紙だけ**。

## 4. ロゴ

- ロゴは **`assets/logo/mirai-logo-black.png`** を使い、**表紙・裏表紙のみ**に置く。
- 青背景の上では `filter: brightness(0) invert(1)` で白く反転（`example-deck.html` 参照）。

## 5. イラスト・画像

- イラストは **`assets/illust/` のSVG** から内容に合うものを選ぶ。配色が青系で統一されているので複数使っても馴染む。
- 写真を使う型（型H/I/J）は、本来は**伝えたい内容に関連する写真**を入れる。手元に写真が無い場合は `assets/gradient/` のブルー背景で代用できる。
- 写真の上に文字を乗せるときは**濃紺の半透明オーバーレイ**（`--overlay`）を重ねて文字を読みやすくする。

## 6. 使えるフォーマット（これ以外の形では作らない）

`slides.css` のクラスと、それぞれの型の考え方・用途。

| 型 | クラス | 考え方・用途 | 内容 |
| --- | --- | --- | --- |
| A | `slide--basic` | 文字にメリハリ／余白はバランス | 白地・左揃えのタイトル＋本文 |
| B | `slide--center` | 中央揃えが効果的／余白は重要 | 強調メッセージを中央寄せ（小さい一文＋大きい言葉） |
| C | `slide--blue` | 数字を透かして見せる | 青背景・白い大タイトル＋透かし数字（章扉・強調） |
| D | `slide--cover-illust` | 扉にイラストをいれても | 青背景・大タイトル＋右にイラスト＋背景に透かし文字 |
| E | `slide--illust` | イラストをいれると／タイトル青色 | 左に文字（青タイトル可）＋右にイラスト |
| F | `slide--illust-center` | 売上がアップしています | 中央にタイトル＋1枚のイラスト |
| G | `slide--icons` | 計算・貯金・パソコン・書類 | アイコン横並び＋ラベル（ピンク差し色） |
| H | `slide--photos` | そろっていると美しい／目立たせたい部分以外は薄く | 写真3枚を揃えて並べる（注目以外は薄く） |
| I | `slide--split` | メリハリをつける（左に画像とオーバーカラー） | 左半分に写真＋番号、右半分に文字 |
| J | `slide--photo-cover` | 背景は画像にオーバーカラー | 写真全面＋オーバーカラー＋番号＋大タイトル（章扉） |
| K | `slide--kpi` | 数字で羅列するとき | タイトル大きく・数字と文字は小さく（単位はさらに小さく） |
| L | `slide--list` | スライド資料デザインのコツ | 番号付きリスト（左揃え） |
| M | `slide--table` ＋ `.tbl` | 表スライド,文字は中央揃え,数字は右揃え,罫線は薄く | 表。黒ヘッダー＋行ラベルはグレー。**見出しは中央揃え／数字は右揃え／罫線は薄く／角丸**。強調は強調列だけ `.em`（ヘッダー=ピンク・セル=薄ピンク） |
| M2 | `slide--table` ＋ `.cmp` | 表スライドパターン２,強調したい時 | 比較表。記号（◎○△×）＋短い説明を中央に。**自社列だけ青ヘッダー＋青枠で浮かせて強調**。記号色＝◎○ピンク／△緑／×グレー |
| N | `slide--flow` | 順番,色1つだけ変えて強調 | 横並びフロー。**強調するなら1ステップだけピンク（`.em`）／強調せず順序を見せるだけなら全部同じ色に統一（`.flow-row.is-uniform`）** |
| O | `slide--section-cover` | タイトルやセクションごとのトップページ | 青背景・四辺の余白をそろえる・左上に大タイトル＋左下に説明＋右下に大きな番号 |
| P | `slide--data` | データ報告にイラスト付き | 白地・中央タイトル・3列（ラベル＋イラスト＋大きい数字／単位は小さく） |

表紙＝`slide--title-page`、裏表紙＝`slide--end`（この2枚だけロゴを使う）。

新しいスライドは、必ず上の型のいずれかを使う。色・サイズは `tokens.css` の変数から参照し、直接ベタ書きしない。
